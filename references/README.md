# Canonical reference pack

This directory is the single source of truth for shared fakegreg references.

Use these files from skills, docs, prompts, and eval scripts:

- `SENSIBILITIES.md` — distilled Greg observations from the gallery and exemplar work.
- `meridian-greg.html` — canonical cleaned Meridian seed.
- `greg-meridian.png` — visual target screenshot for the canonical seed.
- `STYLE_PRIMITIVES.md` — reusable Greg primitives independent of page type.
- `PAGE_ARCHETYPES.md` — page-level templates for landing, dashboard, docs, and pricing surfaces.
- `ANTI_EXAMPLES.md` — explicit failure modes and “not Greg” patterns.

The repo should not duplicate these files into each skill directory. Skills should reference this pack directly.
