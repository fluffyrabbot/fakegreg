# Greg Page Archetypes

These archetypes adapt the shared style primitives to different surface types.

## Landing page
- Hero kicker + thesis + proof + CTA + visual stage.
- Stats row.
- Feature grid with tags.
- Mechanism section with prose + code window.
- Production impact section.
- Final CTA card.

## Ops dashboard
- Product header and operator status bar.
- Global health counters.
- Topology or mesh map.
- Active incidents / handoffs / queue depth panels.
- Workflow or timeline strip.
- Short operator guidance notes.

## Docs home
- Fast orientation headline.
- Quickstart command block near the top.
- Pathways by persona or task.
- API / guides / SDK cards with exact labels.
- Recent changes or release notes callout.
- Lower visual noise than a marketing page, but still polished.

## Pricing page
- Strong packaging narrative before tables.
- Clear tier contrasts.
- Numbers that imply serious usage, not toy plans.
- One section that explains deployment / support / enterprise mechanics.
- CTA pairing: self-serve vs contact sales.

## Framework output
- Preserve the same hierarchy and proof rhythm in components.
- Favor a small set of reusable sections over giant monoliths.
- Keep display logic straightforward; the “Greg” quality comes from composition and copy discipline.
